amr-nano-context

Long-read metagenomic resistome profiling: each resistance gene linked to its mobility and its host organism.

code on GitHub · README

What the pipeline reports

One row per resistance gene: the gene, the drug class, the contig it sits on, whether that contig is circular, the mobility call with its evidence, and the host organism assigned from contig taxonomy. Example rows from the mock-community run:

Validation on a known mock community

ZymoBIOMICS Even mock community, Oxford Nanopore GridION (ERR3152364, subsampled to 1.34 Gbp). The truth set is AMRFinderPlus run on each member's reference genome. Zero false positives across 65 raw calls: the pipeline under-reports, it does not invent.

Gene recovery: AMR elements only (28 expected) and all elements (94 expected, including stress and virulence). Host attribution: every call was assigned the correct genus.
